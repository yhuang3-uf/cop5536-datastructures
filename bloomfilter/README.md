# Bloom Filter
Python implementation of a Bloom filter.

Requires Python version 3.10 or newer.

## Files
The HTML files are documentation accompanying the PY files.

 - `bloomdict.py` - The Bloom filter layered on top of a dict, with statistics
   collection hardware tacked on.
 - `bloomfilter.py` - Implementation of the Bloom filter.
 - `montecarlo.py` - Run this file to perform a Monte Carlo simulation of the
   Bloom filter.
 - `run_tests.py` - Unit testing for the Bloom filter
